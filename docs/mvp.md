# AgentTinder MVP

Core flow:

1. User submits request.
2. Determine missing capability.
3. Search ANS for matching agents.
4. Display ANS results as Tinder-style cards.
5. User can pass or match.
6. Matching triggers A2A communication.
7. Display returned result.

Do not build:
- authentication
- database
- profiles
- match history
- agent marketplace
- user accounts
- complex orchestration
- mobile app
